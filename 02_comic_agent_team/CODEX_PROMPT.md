# Codex에게 전달할 메시지

## 1. 작품 시작 시 1회 (작업 안내)

팀장(Claude)이 작품 브랜치를 만든 뒤, 아래 블록의 `<작품명>`을 채워 Codex에 붙여 넣는다.

```
안녕, 나는 Claude야. 16컷 만화 제작팀의 팀장이고, 너는 "작화 담당 A/B"야.
사용자가 우리 둘 사이에서 메시지를 전달해 줄 거야.

- 저장소: solo-design-house/design-projects
- 작품 브랜치: comic/<작품명>
- 작업 폴더: 02_comic_agent_team/work/<작품명>/

그 브랜치를 체크아웃하고 작업 폴더의 아래 3개 파일을 읽어 둬. 앞으로 이 규칙대로만 일해.
1. AGENTS.md — 운영 방식, 쓰기 가능 경로, git 규칙
2. roles/04_artist.md — 묶음 처리 순서, 요청 문장 조립, 보고 형식
3. jobs/SCHEMA.md — 지시서와 결과 기록 형식

핵심만 다시 적으면:
- 이미지는 이 세션의 이미지 도구로 직접 만든다. codex exec는 쓰지 않는다.
- 프롬프트는 정해진 순서로 이어 붙이기만 하고 바꾸지 않는다.
- 글자·말풍선 금지, 덮어쓰기 금지, 결과 파일만 커밋해서 작품 브랜치에만 push.

다 읽었으면 "준비 완료"와 함께 이해한 규칙에서 애매한 점만 짧게 알려줘. 아직 아무것도 그리지 마.
```

## 2. 매 작업마다 (처리 요청)

팀장이 지시서 묶음을 push한 뒤 출력한다. 사용자는 그대로 Codex에 붙여 넣는다.

```
처리해: 브랜치 comic/<작품명>, 작업 폴더 02_comic_agent_team/work/<작품명>/, 대상 jobs/<패턴>
```

Codex는 `roles/04_artist.md`의 "보고 형식"으로 답하고, 사용자는 그 답을 그대로 Claude에 붙여 넣는다.
