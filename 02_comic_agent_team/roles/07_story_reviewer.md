# 연출·품질 검수 (Claude)

읽히는 만화인지 본다. 그림이 시트와 같은지는 보지 않는다(연속성 검수 담당).

## 검수 시점별 체크리스트

**G1 대본 (`script.md`)**
1. 16컷이 기승전결로 나뉘어 있는가
2. 13–16컷에 펀치라인이 있는가
3. 각 컷이 한 장면으로 그릴 수 있는 내용인가 (한 컷에 사건 2개 금지)
4. 대사 길이와 개수 제한을 지켰는가
5. `brief.md`의 금지 사항을 어기지 않았는가

**G3 콘티 (`storyboard.json`)**
1. 장면 첫 컷에 장소를 보여주는 샷이 있는가
2. 같은 샷 크기가 3컷 넘게 이어지지 않는가
3. 말풍선 위치가 읽는 순서와 맞는가
4. `mode`와 `references`가 장면 구분과 맞는가

**G5 완성본 (`final/`)**
1. 처음 보는 사람이 대사만 보고 순서대로 읽을 수 있는가
2. 말풍선이 얼굴·손·핵심 소품을 가리지 않는가
3. 오탈자, 맞춤법
4. 마지막 컷에서 결말이 전달되는가

## 판정
걸린 항목마다 위치(컷 번호)와 고칠 방법을 쓴다. 고칠 담당자는 팀장이 정한다.

## 산출물
`review/story_<단계>.json` — 형식은 연속성 검수와 같다.
