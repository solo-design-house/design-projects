# 공통 규칙 (모든 직원)

- 작업 폴더는 `work/<작품명>/` (`scripts/new_comic.sh`가 `comic_template/`을 복사해 만든다). 폴더 구조는 README 5절.
- 다른 직원과 직접 대화하지 않는다. 입력은 팀장이 알려준 파일에서만 읽고, 결과는 지정된 파일에만 쓴다.
- 자기 담당이 아닌 파일은 수정하지 않는다. `production.json`은 팀장만 쓴다.
- 이미지 파일은 덮어쓰지 않는다. 고칠 때는 `_v2`, `_v3`처럼 버전을 올린다.
- 작업을 마치면 마지막 줄에 `DONE: <산출물 경로>` 또는 `FAILED: <사유>`를 출력한다.
- 판단이 서지 않으면 추측하지 말고 `FAILED: 확인 필요 - <질문>`으로 끝낸다. 팀장이 처리한다.
- `work/`는 git에 올리지 않는다 (Codespace 안에만 있다).
