# 식자·편집 (Claude)

## 입력
`passed` 상태의 컷 16장, `storyboard.json`, `bible/style.md`

## 형식: 세로 스크롤

| 항목 | 값 |
|---|---|
| 가로폭 | 800px (컷 이미지는 가로폭에 맞춰 축소) |
| 같은 장면 안 컷 간격 | 60px |
| 장면 전환 간격 | 240px 이상 (긴장·시간 경과는 더 넓게) |
| 배경 | 흰색 |
| 가로 컷 (`landscape`) | 800×533 |
| 세로 컷 (`portrait`) | 800×1200 |

## 글꼴 (세트 B)

| 용도 | 글꼴 | 굵기·처리 |
|---|---|---|
| 기본 대사 (`normal`) | 나눔스퀘어라운드 | Bold |
| 외침 (`shout`) | 주아 (Jua) | 기본 크기의 1.3배, 들쭉날쭉한 말풍선 |
| 속마음 (`thought`) | 개구 (Gaegu) | Regular, 점선 또는 구름 말풍선 |
| 효과음 (`sfx`) | 검은고딕 (Black Han Sans) | 흰 테두리, 필요하면 기울임 |

- 모두 무료 상업용. 내려받을 때 라이선스 파일을 `fonts/LICENSES/`에 함께 보관한다.
- 주아·개구·검은고딕은 Google Fonts, 나눔스퀘어라운드는 네이버 한글한글 아름답게에서 받는다.
- 기본 대사 크기: 가로폭 800px 기준 26px 전후. 휴대폰에서 읽히는지 확인한다.

## 순서
1. 입력 확인: 16컷 모두 `production.json`에서 `passed`(또는 `passed_with_issues`)이고 `passed_file`이 있는지 본다. 빠진 컷이 있으면 `FAILED`.
2. 조판 실행: `scripts/letter.py work/<작품명>` (요청서가 분할을 원하면 `--split`).
   스크립트가 하는 일: 컷을 `aspect` 비율로 중앙 기준 자르기 → 가로 800px로 축소 → 말풍선(보통·외침·속마음)과 효과음 합성 → 컷 사이 여백 말풍선 배치 → 장면 전환 간격으로 세로 조판 → `lettered/`, `final/comic.png`(, `final/parts/`).
3. 스크립트 경고를 확인한다. 세트 B 글꼴이 없어 대체 글꼴을 썼다는 경고가 있으면 최종 보고에 적는다.
4. 결과를 직접 열어 확인한다.
   - 자르기 때문에 얼굴이나 중요한 행동이 잘린 컷
   - 말풍선이 얼굴·손·핵심 소품을 가리는 컷
   - 글자가 말풍선 밖으로 넘치는 곳
   문제가 있으면 컷 번호와 고칠 방법(말풍선 `position` 변경 / 다시 그리기)을 팀장에게 보고한다. `storyboard.json`은 직접 고치지 않는다.

## 산출물
