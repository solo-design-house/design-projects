# 식자·편집 (Claude)

## 입력
`passed` 상태의 컷 16장, `storyboard.json`, `bible/style.md`

## 형식: 세로 스크롤

| 항목 | 값 |
|---|---|
| 가로폭 | 800px (컷 이미지는 가로폭에 맞춰 축소) |
| 같은 장면 안 컷 간격 | 60px |
| 장면 전환 간격 | 240px 이상 (긴장·시간 경과는 더 넓게) |
| 배경 | 흰색 |
| 가로 컷 (`landscape`) | 800×533 |
| 세로 컷 (`portrait`) | 800×1200 |

## 글꼴 (세트 B)

| 용도 | 글꼴 | 굵기·처리 |
|---|---|---|
| 기본 대사 (`normal`) | 나눔스퀘어라운드 | Bold |
| 외침 (`shout`) | 주아 (Jua) | 기본 크기의 1.3배, 들쭉날쭉한 말풍선 |
| 속마음 (`thought`) | 개구 (Gaegu) | Regular, 점선 또는 구름 말풍선 |
| 효과음 (`sfx`) | 검은고딕 (Black Han Sans) | 흰 테두리, 필요하면 기울임 |

- 모두 무료 상업용. 내려받을 때 라이선스 파일을 `fonts/LICENSES/`에 함께 보관한다.
- 주아·개구·검은고딕은 Google Fonts, 나눔스퀘어라운드는 네이버 한글한글 아름답게에서 받는다.
- 기본 대사 크기: 가로폭 800px 기준 26px 전후. 휴대폰에서 읽히는지 확인한다.

## 순서
1. 글꼴 4종을 `fonts/`에 준비한다.
2. 컷 비율을 맞춘다. 이미지 도구는 비율을 정확히 지키지 않는다 (테스트에서는 요청과 관계없이 1536×1024).
   - `landscape`는 3:2, `portrait`는 2:3이 되도록 **중앙 기준으로 잘라낸다**. 인물 얼굴과 `empty_area`가 잘리지 않는지 확인한다.
   - 잘라서 해결되지 않으면 팀장에게 보고한다 (다시 그리기 필요).
3. 말풍선 합성 스크립트를 만든다(PIL 또는 SVG). 같은 스크립트로 16컷을 모두 처리한다.
   - 말풍선 모양: 보통·외침·속마음
   - 꼬리 방향은 화자 쪽으로 둔다.
   - `position`이 컷 안이면 `empty_area`에 넣는다. 자리가 부족하면 글자를 줄이지 말고 팀장에게 보고한다.
   - `gutter-above` / `gutter-below`이면 컷 위·아래 여백에 놓고, 꼬리만 컷 안 화자 쪽으로 넣는다. 그만큼 컷 간격을 늘린다.
4. 컷별로 `lettered/pNN.png`를 만든다 (여백 말풍선은 조판 단계에서 합성).
5. 세로로 조판한다. 위 표의 간격을 쓰고, 장면 번호가 바뀌는 곳에 장면 전환 간격을 둔다.
6. 내보낸다.
   - `final/comic.png` — 세로로 긴 PNG 1장
   - 요청서가 분할을 원하면 `final/parts/part_01.png` …: 높이 1600px 안팎에서 **컷 사이 여백**을 기준으로 자른다 (컷이나 말풍선 중간을 자르지 않는다).

## 산출물
