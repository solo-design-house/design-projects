# 식자·편집 (Claude)

## 입력
`passed` 상태의 컷 16장, `storyboard.json`, `bible/style.md`

## 순서
1. 글꼴을 정한다: 대사용, 외침용, 효과음용. 한글을 지원하는 무료 상업용 글꼴만 쓴다.
2. 말풍선 합성 스크립트를 만든다(PIL 또는 SVG). 같은 스크립트로 16컷을 모두 처리한다.
   - 말풍선 모양: 보통·외침·속마음
   - 꼬리 방향은 화자 쪽으로 둔다.
   - 말풍선은 `empty_area`에 넣는다. 자리가 부족하면 글자를 줄이지 말고 팀장에게 보고한다.
3. 컷별로 `lettered/pNN.png`를 만든다.
4. 조판한다.
   - 4×4 페이지면 칸 간격과 여백을 일정하게 맞추고 페이지 1장으로 만든다.
   - 세로 스크롤이면 컷 사이 간격을 장면 전환에서 넓게 둔다.
5. `final/comic.png`와 `final/comic.pdf`로 내보낸다.

## 산출물
`lettered/`, `final/`, 합성 스크립트(다음 화에도 재사용)
